# Plan 3.2: Comparative Visualizations Suite & Figures Generation

## Objective
Implement a modular Matplotlib plotting engine (`connect4/benchmark/plotter.py` and CLI `plotter_cli.py`) capable of parsing empirical tournament metrics and rendering 4 publication-quality 300 DPI figures in `docs/figures/` (Execution Time vs. Depth, Log-scale Nodes vs. Depth, Win-Rate Matrix Heatmap, and Peak Memory Footprint).

## Context
- `.gsd/SPEC.md`
- `.gsd/DECISIONS.md` (`[DECISION-006]`)
- `.gsd/phases/3/RESEARCH.md`
- `connect4/benchmark/instrumentation.py`
- `connect4/benchmark/runner.py`
- `docs/figures/`

## Tasks

<task type="auto" effort="medium">
  <name>Build Benchmark Plotter Engine</name>
  <files>connect4/benchmark/plotter.py, connect4/benchmark/__init__.py, plotter_cli.py</files>
  <action>
    Create `connect4/benchmark/plotter.py`:
    - Use `matplotlib.use("Agg")` for headless / cross-platform rendering.
    - Set modern academic styling (clean grid, distinctive palette, bold titles, annotated values).
    - Functions:
      1. `plot_execution_time_vs_depth(data, output_path)`: Curves for Minimax, Alpha-Beta (with/without move ordering), and MCTS thinking time budgets.
      2. `plot_nodes_expanded_log_scale(data, output_path)`: Semi-log plot showing exponential growth of Minimax vs. reduced branching factor of Alpha-Beta vs. MCTS simulation iterations.
      3. `plot_winrate_matrix_heatmap(matrix, output_path)`: Annotated head-to-head win-rate heatmap across Random, Minimax, Alpha-Beta, Iterative Deepening, and MCTS.
      4. `plot_memory_footprint(data, output_path)`: Bar chart comparing peak heap allocation (`tracemalloc` KB/MB) across algorithms.
      5. `generate_all_figures(output_dir="docs/figures")`: Orchestrator that generates all 4 figures.
    - Provide cached representative tournament data for instant generation, with `--live` flag to run real-time matches via `BenchmarkRunner`.
    - Create `plotter_cli.py` CLI interface.
    - Export functions in `connect4/benchmark/__init__.py`.
  </action>
  <verify>python plotter_cli.py --output-dir docs/figures</verify>
  <done>All 4 figures generated as high-resolution 300 DPI PNGs in docs/figures/.</done>
</task>
