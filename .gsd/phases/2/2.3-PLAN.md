# Plan 2.3: Multi-Game Benchmark Runner & Pygame GUI Skeleton

## Objective
Implement an automated multi-game benchmarking harness (`BenchmarkRunner`) capable of running $N$ seeded matches with alternating first-mover turns, and build an interactive Pygame graphical interface (`Connect4Pygame`) with visual board rendering and click-to-drop controls.

## Context
- `.gsd/SPEC.md`
- `.gsd/DECISIONS.md` (`[DECISION-004]`)
- `.gsd/phases/2/RESEARCH.md`
- `connect4/core/board.py`
- `connect4/agents/base.py`
- `connect4/agents/mcts_agent.py`
- `connect4/benchmark/instrumentation.py`

## Tasks

<task type="auto" effort="medium">
  <name>Build Multi-Game Automated Benchmark Harness</name>
  <files>connect4/benchmark/runner.py, connect4/benchmark/__init__.py, benchmark_cli.py</files>
  <action>
    Create `connect4/benchmark/runner.py`:
    - `BenchmarkMatchResult`: Dataclass storing games played, agent1 wins, agent2 wins, draws, average move times, average nodes/simulations, peak memory per agent.
    - `BenchmarkRunner`:
      - Methods to run a series of $N$ games between two agents.
      - Alternates first-player (Player 1 / Red) across games to eliminate first-mover advantage bias.
      - Provides a formatted summary table displaying win rates, decision latencies, and search expansions.
    - Export `BenchmarkRunner` in `connect4/benchmark/__init__.py`.
    - Create `benchmark_cli.py` entrypoint allowing command-line invocation (e.g. `python benchmark_cli.py --agent1 alphabeta --agent2 mcts --games 10`).
  </action>
  <verify>python -c "from connect4.benchmark import BenchmarkRunner; print(BenchmarkRunner)"</verify>
  <done>BenchmarkRunner imports and can execute automated multi-game evaluation matches.</done>
</task>

<task type="auto" effort="medium">
  <name>Implement Pygame GUI Skeleton</name>
  <files>connect4/gui/pygame_app.py, connect4/gui/__init__.py, gui_main.py</files>
  <action>
    Create `connect4/gui/pygame_app.py`:
    - Pygame Connect Four window (700x700px: 600px grid + 100px header).
    - Draw visual blue board, circular slots (black for empty, red for P1, yellow for P2).
    - Mouse movement handler: render floating disc in header above corresponding column.
    - Click handler: drop disc into clicked column if valid move.
    - Agent move dispatcher: seamlessly compute and drop agent discs.
    - Headless mode check / flag: support `--headless` or `HEADLESS` environment variable for test environments.
    - Create `gui_main.py` entrypoint to launch Pygame interface (`python gui_main.py --agent mcts`).
  </action>
  <verify>python -c "from connect4.gui import Connect4Pygame; print(Connect4Pygame)"</verify>
  <done>Pygame application module imports cleanly and supports interactive launch.</done>
</task>
