## Accomplishments

1. **MCTS Implementation (`connect4/agents/mcts_agent.py`)**:
   - `MCTSNode`: State tracking, tree navigation, untried moves pool, and UCT calculation:
     $$UCT(i) = \frac{w_i}{n_i} + C_p \sqrt{\frac{2 \ln N}{n_i}}$$
     with deterministic tie-breaking via agent's seeded `self.rng`.
   - `MCTSAgent`: 4-stage search loop (Selection -> Expansion -> Simulation -> Backpropagation), tactical immediate win/threat detection, and dual-mode search budgeting (fixed simulations count or wall-clock time limit).
   - Exported in `connect4/agents/__init__.py`.

2. **CLI Registration & Arguments (`main.py`)**:
   - Added `mcts` to agent choices for Player 1 and Player 2.
   - Added `--simulations1`, `--simulations2`, `--time-limit1`, and `--time-limit2` CLI parameters.
   - Verified via live match simulation (`AlphaBeta` vs `MCTS`).
