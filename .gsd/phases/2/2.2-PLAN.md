# Plan 2.2: Monte Carlo Tree Search (MCTS) Agent

## Objective
Implement a robust Monte Carlo Tree Search (MCTS) agent utilizing the Upper Confidence Bound applied to Trees (UCT) selection policy, random rollout simulations, backpropagation, and dual-mode budgeting (fixed simulations and wall-clock time limit).

## Context
- `.gsd/SPEC.md`
- `.gsd/DECISIONS.md` (`[DECISION-003]`)
- `.gsd/phases/2/RESEARCH.md`
- `connect4/core/board.py`
- `connect4/agents/base.py`

      - `best_child(c_param=1.414)`: Return child maximizing UCT score.
    - `MCTSAgent(Agent)`:
      - Parameters: `simulations: int = 500`, `time_limit: Optional[float] = None`, `exploration_constant: float = 1.414`, `seed: Optional[int] = None`.

        - Root expansion.
        - Loop while within budget (simulations count or `time.perf_counter() < deadline`).
        - 4 stages: Selection -> Expansion -> Simulation (rollout) -> Backpropagation.
        - Track `self.nodes_expanded` (increment per simulation rollout / node explored).
        - Select child of root with highest visit count.
    - Export `MCTSAgent` in `connect4/agents/__init__.py`.
